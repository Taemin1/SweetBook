# 서비스 기획: 하루감사 (Haru Gamsa)

> 콘텐츠 서비스가 본체, "감사일기 책 만들기"는 그 위의 부가 기능.

## 한 문장 소개

매일 밤 감사한 일 세 가지를 짧게 기록하고, 쌓인 기록을 연말에 한 권의 책으로 남기는 감사일기 서비스.

## 타겟 사용자 (페르소나)

- **이름(가상)**: 김지은, 29세, 마케팅 3년차 직장인
- **상황**: 자기계발·마음챙김에 관심 있지만 거창한 다이어리 앱은 부담스러움. 퇴근 후 잠들기 전 스마트폰으로 하루를 짧게 정리하고 싶어함.
- **기기**: 평일 밤 대부분 **모바일**(침대에서), 주말에 가끔 데스크톱으로 지난 기록을 돌아봄.
- **니즈**:
  - 부담 없이 짧게 쓰고 싶다 (3줄 이내)
  - 습관을 이어가고 싶다 (연속 기록에 동기부여)
  - 1년치 기록을 연말/생일 선물용 책으로 남기고 싶다
- **이 페르소나가 이 서비스를 안 쓰는 상황**: 거창한 자서전을 쓰고 싶은 사람, 여러 장의 사진을 중심으로 기록하고 싶은 사람 → 다른 서비스가 더 적합. 우리는 "짧고 꾸준한 텍스트 기록"에 집중.

## 핵심 기능 (Lv1 — 콘텐츠 서비스 본체)

1. **오늘의 감사 작성**: 감사한 일 최대 3개(각 1줄), 기분 태그 1개 선택, 자유 메모(선택)
2. **하루 1건 제한**: 같은 날짜에 중복 작성 불가, 대신 수정 가능 (일기 앱 특성상 "오늘의 기록"은 유일해야 자연스러움)
3. **목록 조회**: 최신순 리스트, 날짜·기분태그 표시, 기분별 필터
4. **상세보기/수정/삭제**
5. **연속 기록 스트릭**: 오늘 작성 여부와 연속 일수를 홈 상단에 표시 (습관형 서비스의 핵심 동기부여 장치)

## 부가 기능 (Lv2 — 자체 주문)

1. **"감사일기 책 만들기" 주문**: 기간 선택(최근 3개월/6개월/1년/직접 지정) → 해당 기간 내 일기 건수 자동 계산 → 책 제목 입력 → 주문 생성
2. **주문 상태 관리**: `pending`(제작 대기중) → `processing`(책 만드는 중) → `completed`(제작 완료)
3. **내 주문 목록**: 상태 뱃지, 주문일, 포함 기간, 포함 일기 수
4. **관리자용 주문 관리 화면** (`/admin/orders`, 선택 구현): 전체 주문 조회, 상태 변경(다음 단계로 전이 트리거 — 결제/배송 연동이 없으므로 상태 변화를 보여주려면 수동 트리거가 필요), JSON/CSV 내보내기
5. **명시적으로 안 함**: 결제, 배송 추적, 회원 인증, 실제 인쇄용 PDF 생성

## Lv3 — UI/UX 설계 판단

| 상황 | 판단 |
|---|---|
| 첫 방문(빈 목록) | "아직 감사일기가 없어요" + 오늘 작성 CTA를 크게 노출 |
| 오늘 이미 작성함 | 홈에서 "오늘의 감사 다시 보기/수정" 동선으로 전환, 중복 작성 폼 노출 안 함 |
| 주문 상태 | pending/processing/completed를 사용자 언어("제작 대기중" 등)로, 진행 바 형태로 시각화 |
| 로딩 | 스켈레톤 UI (레이아웃 흔들림 방지) |
| 에러/실패 | 토스트 메시지 + 재시도 버튼, 원인 텍스트는 사용자 언어로 |
| 입력 실수 | 감사한 일 최소 1개 필수, 글자수 제한 실시간 안내 |
| 화면 크기 | 모바일 우선 설계(취침 전 사용 시나리오) — 콘텐츠 폭을 `max-w-2xl`로 제한하고 홈 진입 즉시(스크롤 없이) "오늘의 감사 쓰기" CTA가 보이도록 배치. 데스크톱은 같은 레이아웃이 중앙 정렬되며 여백만 늘어남 |

## 의도적으로 넣지 않은 것 (README에도 명시 예정)

- 회원가입/로그인 → 단일 사용자 가정, 평가 범위(Lv1~Lv3)와 무관하고 심사자가 로그인 없이 즉시 확인해야 하는 요구사항과도 배치되므로 제외
- 결제/배송/실제 인쇄 → 과제 요구사항에서 명시적으로 제외 대상
- 사진 첨부 → 서비스 컨셉을 "짧은 텍스트 기록"에 집중시키기 위해 1차 범위에서 제외 (README "더 시간이 있었다면"에 기재 예정)

## 화면 목록

- `/` 홈: 오늘 작성 상태, 스트릭, 최근 일기 미리보기
- `/entries` 감사일기 목록
- `/entries/new` 오늘의 감사 작성
- `/entries/[id]` 상세/수정
- `/orders` 내 주문 목록
- `/orders/new` 책 주문 만들기
- `/orders/[id]` 주문 상세
- `/admin/orders` 관리자 주문 관리 (선택)

## DB 엔티티 개요

- `entries`: 감사일기 1건
- `orders`: 책 제작 주문 1건
